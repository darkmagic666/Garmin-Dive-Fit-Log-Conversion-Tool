# Garmin-Dive-Log-Conversion-Tool
The primary function of this tool is to convert Garmin dive .fit files into .txt or .srt formats. The .txt files are convenient for further use, while the .srt files can be used directly as subtitles.

How to use:
- Place the files you wish to convert and the program in the same folder.
- Double-click the conversion program.
- Option 1: Convert an existing .txt file into an .srt file.
- Option 2: Convert a .fit file into a .txt file.
- Option 3: Convert a .fit file into an .srt file.
