# Garmin-Dive-Log-Conversion-Tool
The primary function of this tool is to convert Garmin dive `.fit` files into `.txt` or `.srt` formats.  
The `.txt` files are convenient for various other uses,  
while the `.srt` files can be used directly as subtitles.

How to use:
- Place the files you wish to convert in the same folder as the program.
- Double-click the conversion program.
- Option 1: Convert an existing `.txt` file into an `.srt` file (requires entering a start time for the subtitles).
- Option 2: Convert a `.fit` file into a `.txt` file.
- Option 3: Convert a `.fit` file directly into an `.srt` file (requires entering a start time for the subtitles). You can enter an approximate start time and then fine-tune the subtitles later using software such as PotPlayer.
